## Definition of a Library and examples.

Is a collection of reusable functions that you call as needed, without controlling your program's structure
1. React for UI
2. Numpy for numerical computing

A package management system automates installing, updating and managing, external dependencies

2. pip for python

## What Git is and its most important commands.

Git is a distributed version control system; essential commands include git clone, git add, git commit, git push, git pull and git meger

# Summary Topic 5

## What GitHub is, including the definitions of Pull Request and Merge.

Github is a cloud-based Git repository hosting service
A pull request is a request to merge changes form one branch into another, often with code review, and a Merge is the action of integrating those changes into the target branch.

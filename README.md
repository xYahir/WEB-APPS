### 2. Definition of a Web Server and examples
A Web Server is a software/hardware that stores, processes, and delivers web pages to users via HTTP. It receives a request from a browser and sends back  the rsponse (HTML, CSS, images).

1. Apache
2. Nginx

### 3. Definition of a Database Managment System (DBMS) and examples
A DBMS is a software that allows to create, manage, organize, and query database. It helps to store retrieve, update and secure data in an efficient way.

1. MySQL
2. PostgreSQL

### 4. Definition of a Runtime Environment or Interpreter and examples
**Runtime Environment:** Is the environmentwhere a program is a executed. It provides libraries, dependencies, and resources needed for the code to run
**Interpreter:** Is a program thats reads and executes code line by line, without needing to compile it first

1. Node.js (JavaScript Runtime)
2. Python Interpreter

### web-apps

Topic 1 Summary - Student A
1. Local Environment vs. Production Environment
 Local Environment: The personal computer or workstation where a developer writes, tests, and debugs code. Changes made here are only visible to the developer and do not impact end users or the live application.
 Production Environment: The live, public-facing server or cloud infrastructure where the finalized version of the application runs, making it accessible to all real-world users.
Examples:
 Local: Running a development server on your laptop accessible via ⁠http://localhost:3000⁠.
 Production: Deploying the web application to AWS (Amazon Web Services) or Vercel under a public domain like ⁠[https://my-app.com](https://my-app.com)⁠.
2. Web Server
A Web Server is software (or the underlying hardware) responsible for processing incoming HTTP/HTTPS requests sent by clients (such as web browsers). Its main job is to serve static files (HTML, CSS, images) or route dynamic requests to application services.
Examples:
1. Nginx: A high-performance web server and reverse proxy known for its speed and efficient handling of concurrent connections.
2. Apache HTTP Server: A battle-tested, open-source web server widely used across the web.
3. Database Management System (DBMS)
A DBMS is software designed to store, retrieve, manage, and query structured or unstructured data securely and efficiently.
Examples:
1. PostgreSQL: An open-source, object-relational database management system (RDBMS) renowned for its reliability and complex query support.
2. MongoDB: A popular non-relational (NoSQL) document database that stores data in flexible, JSON-like structures.
4. Runtime Environment / Interpreter
A Runtime Environment or Interpreter provides the underlying infrastructure, libraries, and engines necessary to process, execute, and manage code written in a specific programming language on an operating system.
Examples:
1. Node.js: An open-source, cross-platform JavaScript runtime built on Chrome's V8 engine that enables server-side JavaScript execution.
2. CPython: The default, reference open-source interpreter for the Python programming language.
5. Integrated Development Environment (IDE)
An IDE is a comprehensive software application that bundles essential development tools—such as a source code editor, build automation tools, version control integration, and a debugger—into a single interface.
Examples:
1. Visual Studio Code (VS Code): A lightweight, highly extensible code editor widely favored across the industry.
2. IntelliJ IDEA: A feature-rich IDE developed by JetBrains, primarily used for Java and Kotlin development.
